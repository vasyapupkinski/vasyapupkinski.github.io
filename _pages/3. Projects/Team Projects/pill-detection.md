## 프로젝트 개요
비정상적인 모델 성능 지표(mAP 0.99)의 근본 원인을 데이터 기저에서 파헤치고, 통계적 오디팅을 통해 AI 서비스의 실무 신뢰도를 확보한 **Data-Centric** 프로젝트입니다. 단순 모델 튜닝을 넘어 데이터 누수(Leakage)를 규명하고 정제하는 전 과정을 주도했습니다.

## 주요 기술 스택
- **Computer Vision**: `YOLOv8n`, `OpenCV` (Preprocessing)
- **Data Centric**: 다각적 임계 통계 EDA, `Pseudo-labeling` (데이터 복원), `HSV Variable Control`
- **Optimization**: 7:1.5:1.5 계층적 분할(Stratified Split) 기반 데이터 누수 차단

---

## 핵심 성과 및 기술적 도전

### 1. "가짜 정확도"의 허구성과 데이터 누수 규명
초기 모델이 mAP 0.99라는 경이로운 수치를 기록했으나, **"과연 이 점수가 지능적 학습의 결과인가?"**라는 비판적 의구심으로 오디팅을 시작했습니다.
- **문제 발견**: 데이터가 통제된 환경(동일 배경/조명)에서 촬영되어, 모델이 알약의 특징이 아닌 **배경 정보를 암기(과적합)**하고 있음을 발견.
- **EDA 중심의 규명**: 실루엣 분석(-0.49) 및 클러스터링을 통해 학습-검증 데이터 간의 강력한 데이터 누수(Leakage)를 통계적으로 입증.

### 2. 의사 레이블링(Pseudo-labeling)을 통한 데이터 무결성 복원
라벨링 누락 및 오염 데이터를 수동으로 수정하는 한계를 극복하기 위해 기술적 자동화 전략을 도입했습니다.
- **데이터 복원**: 정상 데이터로 사전 학습된 모델을 활용해 오염된 데이터셋 내 **840여 개의 라벨 오류를 전수 복구 (57%)**.
- **패턴 역추적**: 파일명 패턴 분석을 통해 누락되었던 소수 클래스(넥시움정 등)를 식별하고 데이터셋에 매핑하여 클래스 불균형 해소.

### 3. 변인 통제 실험 기반의 맞춤형 데이터 증강(Augmentation)
일률적인 데이터 증강이 모델 성능을 오히려 저해한다는 가설을 세우고 실험을 진행했습니다.
- **기하학적 증강 배제**: 데이터의 공간적 편향을 고려할 때, 회전 등의 기하학적 변환이 모델의 학습을 방해함을 인지하고 과감히 배제.
- **HSV 최적화**: 알약 표면의 **'텍스트 각인'** 식별력을 높이기 위해 명도/채도(HSV) 중심의 **11단계 변인 통제 실험**을 주도하여 최적의 하이퍼파라미터 도출.

### 4. 실무 신뢰 마진(Result) 확보
데이터 정제 후 완전 격리된 테스트셋(Train:Val:Test = 7:1.5:1.5)을 재구축하여 환경적 요인이 차단된 상태에서 **최종 mAP@50-95 0.9808**을 달성했습니다. 수치 너머의 데이터 무결성을 증명함으로써 실제 현장에서 작동 가능한 모델의 신뢰성을 확보했습니다.
